# РУКАМИ — Надя: платформа 1С и раннер onec
Мы это **не проверяли** (нет лицензии). Ниже план; команды 1С сверяй с документацией вендора.

## Шаги
1. Узнать: чья лицензия, какого вида (пин-код / программная), на какой машине. Записать в `docs/license.md`.
2. На VPS (по SSH от Есена): установить платформу 1С для Linux и `xvfb`. **Hostname не менять.**
3. Активировать лицензию. Проверить, что работают `1cv8` (DESIGNER) и `ibcmd`. Реальный вывод версии → `docs/evidence/platform-version.txt`.
4. Установить `gitlab-runner` (shell), `OneScript`, `vanessa-runner` (`opm install vanessa-runner`).
5. Раннер: в GitLab создать instance runner с тегом `onec` (Вероника/Есен), затем `ci/scripts/register-runner-onec.sh <glrt-токен>`.
6. Прогнать `ci/scripts/build.sh` руками, поправить под реальные команды. Только после этого в CI variables поставить `ONEC_ENABLED=true`.
7. Прод-сценарий: тестовая копия ИБ → `deploy-prod.sh` с `CONFIRM=yes` → `rollback.sh` → лог.

## Что сохранить
`platform-version.txt` → PR N2-A; `rollback-log.txt` → PR N2-B.
Если лицензии нет: так и напиши в `license.md` («не запущено, нет лицензии»).
