# Как вносить изменения
1. Одна задача — один issue и один PR. Ветка называется как в задаче.
2. Коммиты: `#N: что сделано` (N — номер issue).
3. В PR заполнить шаблон, приложить реальные доказательства в `docs/evidence/` (имена `<зона>-<что>.png|txt`). Не запускалось — писать «не прогнано, потому что …».
4. Нужен 1 approval от другого участника. Автор делает squash-merge сам.
5. Нельзя коммитить секреты, дистрибутивы и лицензии 1С, данные заказчика.
