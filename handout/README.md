# onec-ci-delivery
- `repo/` — базовый каркас репозитория (то, что Есен кладёт в `main` первым коммитом из своего аккаунта). Файлы, которые идут через PR, вынесены в `handout/`.
- `handout/<имя>/` — памятка, файлы и описания PR, готовые ответы на ревью.
- Порядок: сначала Есен публикует `repo/` в `main` и включает защиту ветки; Вероника заводит 15 issues; затем PR.
- Конфликты: E-B (раздел в architecture.md) после E-C; V-B (ссылка на доску в README) после E-A.

## Кто кого ревьюит
| Автор | A и C проверяет | B проверяет |
|---|---|---|
| Есен | Вероника | Соня |
| Вероника | Настя | Есен |
| Настя | Надя | Вероника |
| Надя | Соня | Настя |
| Соня | Есен | Надя |
