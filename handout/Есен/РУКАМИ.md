# РУКАМИ — Есен: раскатка стенда на VPS
Не проверено нами: HTTPS, реальный VPS. Проверено в песочнице: всё из шагов 5–8.

## Шаги
1. VPS: Ubuntu 22.04/24.04, 4 vCPU, 16 ГБ, 100 ГБ. **Hostname не менять** (лицензия 1С).
2. Docker: `curl -fsSL https://get.docker.com | sh`; создать пользователя без root и добавить в группу docker.
3. Firewall: `ufw allow 22,80,443/tcp && ufw enable`. Порт 9000 (Sonar) снаружи закрыт, пока команда не решит иначе.
4. Sonar на хосте: `sysctl -w vm.max_map_count=262144` (и в `/etc/sysctl.d/`).
5. `git clone <репо> && cd 1c-pp/docker && cp .env.example .env` → заполни пароли и домен. `https` в `GITLAB_EXTERNAL_URL` только если есть домен с открытыми 80/443.
6. `../ci/scripts/fetch-bsl-plugin.sh && docker compose up -d` → ждать `healthy` (GitLab ~5 мин).
7. Sonar `:9000`: admin/admin → новый пароль → `SONAR_ADMIN_PASSWORD=... ../ci/scripts/sonar-setup.sh`.
8. Проверка бэкапа: `../ci/scripts/backup.sh`, создай тестовый проект, `../ci/scripts/restore.sh <метка>` → проект исчез.
