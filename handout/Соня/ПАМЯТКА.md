## Один раз настроить git
`git clone https://github.com/xzx-xzxx/1c-pp.git && cd 1c-pp`, затем `git config user.name "<имя>"` и `git config user.email "<почта GitHub>"`. Коммиты только из своего аккаунта.

2. Скопируй содержимое `S-A/files/` в корень клона (пути уже совпадают с репозиторием). Прочитай файлы, поправь по реальности.
