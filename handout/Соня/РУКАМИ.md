# РУКАМИ — Соня: demo-ветки и проверка quality gate
Сценарий проверен в песочнице: хорошая ветка зелёная, плохая красная, merge блокируется.

## Шаги (когда у Насти готов `onec-config` с `src/`)
1. Ветка `feature/good-change` от `main`: добавь безобидную функцию в любой модуль. Коммит `#N: хорошая правка`, push, MR.
2. Ветка `feature/bad-change` от `main`: добавь модуль с кодом
```
Процедура Подключиться() Экспорт
	Пароль = "SuperSecret123";
	Путь = "C:\Temp\data.txt";
	Адрес = "192.168.1.10";
КонецПроцедуры
```
   Коммит, push, MR.
3. Pipeline стартует сам. Ожидание: good — `success`, bad — `failed` (lint: `QUALITY GATE STATUS: FAILED`), кнопка Merge недоступна.
4. Если результат другой — не подгоняй: открой Sonar → Issues, посмотри серьёзность правил, напиши Есену/Веронике.
5. В Sonar посмотри, какие правила реально Critical, и обнови таблицу в `docs/pipeline.md`.
