# Сценарий демо (живой, одним прогоном)

Предусловие: стенд поднят, ветки `feature/good-change` и `feature/bad-change` созданы людьми.
1. Показать GitLab, группу, таблицу ролей, защищённые ветки.
2. MR из `feature/good-change` → pipeline стартует сам, `lint` зелёный, merge доступен. (Есть лицензия: показать `build` и `test`.)
3. MR из `feature/bad-change` (критичная диагностика BSL, например `UsingHardcodeSecretInformation`) → pipeline красный, Merge заблокирован, причина видна в MR.
4. Показать manual-job `deploy-prod`, сценарий бэкапа и отката.
5. (Есть лицензия) merge в `release/*` → тестовый контур обновляется сам.

Запасной план: заранее записанные прогоны. Скрины и логи — только с реального стенда, в `docs/evidence/`.
