# РУКАМИ — Настя: демо-конфигурация в EDT
Мы не проверяли EDT. Это шаги по общей логике, поправь по факту и запиши в `docs/dev-guide.md`.

## Шаги
1. Поставить 1C:EDT (по инструкции вендора). Проверить, что запускается.
2. Создать проект конфигурации `demo` (File → New → 1C:Enterprise Configuration Project).
3. Добавить минимум: справочник `Номенклатура`, общий модуль `Расчеты` с кодом:
```
Функция Сумма(А, Б) Экспорт
	Возврат А + Б;
КонецФункции
```
4. Исходники EDT-проекта (папка `src`) → в `demo-config/` репо платформы **и** в корень `src/` проекта `onec-config` в GitLab (CI ждёт `src/**/*.bsl`).
5. Открой проект из клона GitLab в EDT (File → Import) — скрин.
6. Пройди `docs/dev-guide.md` руками (клон → ветка → правка в EDT → коммит → MR) и поправь текст.
