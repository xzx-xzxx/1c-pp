# Демо-конфигурация

Здесь должны лежать исходники учебной/открытой конфигурации 1С в формате 1C:EDT (без данных заказчика).

## Выгрузка из EDT в GitLab
1. В EDT: File → Import → конфигурацию (из файла `.cf`/хранилища) в проект EDT.
2. Проект EDT лежит в каталоге Git-репозитория; проверить `.gitignore` и `.gitattributes`.
3. `git add -A && git commit -m "#N: демо-конфигурация" && git push`.

## Решение по конфигурации
Берём **собственную минимальную учебную конфигурацию**, созданную в EDT (1–2 справочника, документ, общий модуль с несколькими процедурами на BSL). Причины: нет вопросов лицензии и данных заказчика, быстрый lint и сборка, легко сделать «плохую» правку для демо. Автор — Настя (PR N1-A).

Статус: исходники **не добавлены**.
