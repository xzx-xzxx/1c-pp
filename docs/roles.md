# Роли и права

| Роль в процессе | Роль в GitLab | Может | Не может |
| --- | --- | --- | --- |
| Разработчик | Developer | push в `feature/*`/`hotfix/*`, открывать MR | push в `main`/`release/*`, ставить теги, merge в защищённые |
| Ревьюер | Developer + назначение в MR | комментировать, ставить threads | merge в защищённые ветки |
| Ответственный за релиз | Maintainer | merge в `main`/`release/*`, теги `v*`, запуск `deploy-prod` | force push (выключен для всех) |
| Администратор | Owner | пользователи, runner'ы, настройки, бэкап | — |

Свободных (общих) аккаунтов нет: каждый вход — под личным именем, 2FA.
