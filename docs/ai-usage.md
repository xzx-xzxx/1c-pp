# Использование ИИ

| Вопрос | Ответ |
| --- | --- |
| Зачем | Ускорить подготовку каркаса репозитория, скриптов и черновиков документов; часть работы (DevOps-обвязка, BSL-конфиги) не по основным навыкам команды |
| Инструмент | Claude Code (Anthropic), в облачной сессии; лицензия/подписка — по условиям Anthropic, использование в рамках учебного проекта |
| Этапы | структура репозитория, `docker-compose`, `.gitlab-ci.yml`, shell-скрипты, конфиги BSL/Sonar, черновики всех документов, раздаточные материалы (памятки), черновик презентации |
| Что создано ИИ | все файлы-черновики в репозитории на момент первого коммита; доля — почти 100 % исходного текста и кода |
| Что делают люди | запускают и проверяют стенд, правят скрипты по факту прогонов, вычитывают документы, ведут коммиты и PR из своих аккаунтов, ревьюят друг друга |
| Как проверяли работу ИИ | `bash -n` для скриптов (синтаксис); запуск на стенде — **не выполнялся**, результаты прогонов добавляют люди; статусы в `requirements-status.md` честные |
| Известные риски | версии образов, плагинов и команд `ring`/`vrunner` могут требовать правки; ИИ мог ошибиться в деталях платформы 1С |

Описания PR и тексты ревью подготовлены с помощью Claude Code, проверены и опубликованы людьми.

Объём (заполнить из git): строк кода [впиши], строк текста [впиши].
