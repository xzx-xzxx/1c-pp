# Структура этого репозитория

| Папка | Что это | Куда идёт |
| --- | --- | --- |
| `prod/` | **Готовый проект платформы** (docker, ci, скрипты, документы). Это содержимое публичного GitHub-репозитория | в `main` целевого репо |
| `handout/<имя>/` | **Шпоры для участников:** `РУКАМИ.md`, `ПАМЯТКА.md`, файлы и описания PR, готовые ответы на ревью | людям, **в репо платформы не попадает** |

Как это работает:
1. Есен кладёт в `main` целевого репо содержимое `prod/` **без файлов, которые идут через PR** (их список — в таблице PR; они лежат в `handout/<автор>/<PR>/files/`). Готовая «база» без PR-файлов: `dist/onec-ci-delivery/repo/` после `gen`, либо в zip-архиве.
2. Каждый открывает свои PR по `handout/<имя>/ПАМЯТКА.md`, копируя файлы из `<PR>/files/`.
3. `handout/` целиком в целевой репозиторий не коммитится.

Кто кого ревьюит — в `handout/README.md`.
